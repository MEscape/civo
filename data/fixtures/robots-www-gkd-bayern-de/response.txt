# Strategie:
# - Suchmaschinen + KI-Bots: Zugang erlaubt (öffentlicher Datenauftrag)
# - Rechenintensive / interne Pfade: Für alle gesperrt
# - Schadhafte Bots: Komplett ausgeschlossen
#
# Jeder Bot nutzt NUR den spezifischsten Block, der auf ihn passt.
# Ein Bot mit eigenem Block ignoriert "User-agent: *" vollständig.
# Deshalb haben erlaubte Bots KEINEN eigenen Block — sie fallen auf
# "User-agent: *" durch und erben dort die Disallow-Regeln.


# =====================================================================
# GLOBALE REGELN
# Gilt für alle Bots OHNE eigenen Block — also auch Suchmaschinen
# und KI-Bots. Erlaubt alles außer den unten gesperrten Pfaden.
