## Interpretation limits

- Source keywords and distribution formats come from captured metadata. Required record fields and units still require payload-level evidence.
- Open Data Bayern's candidate CKAN-style endpoint returned HTML with HTTP 200. It is not a verified CKAN integration.
- NINA returned an empty JSON array. This verifies an empty response, not a warning-item schema or a continuous absence of warnings.
- Candidate OGC URLs returned errors or capabilities documents. A capabilities response alone does not establish a licensed, working spatial layer.
- Unreadable, blocked, redirected, unlicensed and untested sources remain Not Verified.
- 2026-11-09 data-endpoint probes: robots.txt disallowed Overpass, DWD warnings, GovData CKAN and the council system's OParl path, so no request was sent (see each `attempt.meta.json`). The MaStR robots policy could not be verified, so no request was sent. UBA air-data stations returned HTTP 500 twice. These stay Not Verified; no robots override was used for them.
- Probe scripts use bounded requests and one-second pacing. The explicit --ignore-robots option records the user-authorized advisory override. No browser data requests are needed for snapshots.
